Lab · Goal and objectives

Turn a model that fails into a reliable specialist

Goal

Take a small instruct model that fails at triage and, with QLoRA on a free T4 in minutes, make it reliably emit correct, schema-valid JSON. Then prove it on tickets it never saw.

By the end you can…

  1. Explain base vs instruct, and why we start from instruct
  2. Design a dataset: schema first, balanced labels, train / val / test
  3. Format examples with the chat template, without truncating answers
  4. Load a model in 4-bit and attach LoRA, knowing every setting
  5. Run SFTTrainer within T4 memory limits
  6. Read a loss curve: healthy, overfitting or broken
  7. Evaluate before vs after with task metrics, not just loss
  8. Save, merge and run the fine-tuned model
These match the learning objectives at the top of the notebook, one per notebook section. Read the goal out loud; the objectives are for students to tick off.
