Checkpoint 3 · Loss is not success

“Training loss went down, so the fine-tune worked. Let’s ship.” What’s wrong with that, and which two checks do you demand?

Model answer

Falling training loss only proves the model fits the training examples better, which is also what memorization looks like. Demand: (1) evaluation on a held-out test set against the Stage-1 metric and a real baseline (the prompted base model); (2) a general-capability regression check to catch catastrophic forgetting. Loss is a training diagnostic, not a measure of success.

Low training loss can be memorization. Demand a held-out evaluation against a baseline, plus a regression check. The lab does exactly this: it scores the same 35 held-out tickets before and after training.
